## WHAT I LEARNED — The Training System Core Principles

I've read both coaching documents front to back. Here's what the system teaches:

### 1. Movement Patterns — The Unit of Programming (§1)
**The big idea:** The whole body is covered by THREE movement categories:
- **PUSH** (horizontal/vertical) → trains chest, shoulders, triceps
- **PULL** (horizontal/vertical) → trains back, rear shoulder, biceps, forearms
- **SQUAT/HINGE** (lower body) → trains quads, glutes, hamstrings, entire lower body

The trunk gets trained as a by-product whenever these are done with free weights (it has to brace the spine).

**Rules for the product:**
- Every exercise must be tagged by PATTERN and EQUIPMENT
- A session is complete when it covers push, pull AND lower
- A week is complete when each pattern appears at least TWICE
- Direct arm/calf/trap work is garnish — it goes AFTER the pattern lifts, never as the spine of a session

### 2. Balance is a HARD Constraint (§2)
**The warning from the book:** A body over-developed on one side (chest vs upper back, front vs rear shoulder) STALLS because it resists growth that raises injury risk. This is called one of the most avoidable plateaus.

**Rules for the product:**
- Track weekly pull sets vs push sets
- If pull < push for TWO weeks running → auto-insert row/face-pull/reverse-fly movements
- When a user reports "my chest stopped growing" → check the balance ratio FIRST
- When a user reports shoulder pain on pressing → reduce pressing AND raise upper-back volume (don't just delete pressing)

### 3. Structuring a Week (§3)
**Default for time-poor or beginners:** 3 full-body sessions on non-consecutive days, with 2 rest days before the cycle repeats.

**Cadence rules:**
- Onboarding asks DAYS AVAILABLE and MINUTES PER SESSION
- 3 days or fewer → full-body rotation
- 4 days → upper/lower alternating
- 5+ days → same, but extra days go to CONDITIONING, not more lifting
- NEVER place two heavy sessions on consecutive days
- NEVER place a heavy lower day after a sprint/interval day

**Variety comes from rotating REP SCHEMES**, not from new exercises. The rotation should be visible to the user so Friday feeling different from Monday reads as intentional design.

### 4. Progression — Pick WHICH Knob to Turn (§4)
The book uses SIX distinct progression mechanisms. Each implies a different metric to LOG and a different trigger for the next step:

| Mechanism | What You Track | When to Advance | When to Reset |
|-----------|---------------|-----------------|---------------|
| **Load step** | top-set weight | target reps hit at prescribed rest | two consecutive misses → drop 5-10% |
| **Scheme rotation** | which set×rep combo was used | cycle combinations with similar rep total | full cycle done → add load |
| **Total-rep target** | reps accumulated at fixed load | total reached under the set cap | cap hit → raise load, drop target to floor |
| **Volume ramp** | sets per exercise | add a set every 1-2 weeks | block ends at ~6 weeks |
| **Rest compression** | seconds between sets | every ~2 weeks, cut a fixed slice | rest reaches floor → raise load, restore rest |
| **Density** | total reps in a fixed window | more work than last time, same window | plateau → change the exercise pair |

**Assignment by goal:**
- Strength → load step + scheme rotation
- Hypertrophy → total-rep or volume ramp
- Fat-loss/recomposition → rest compression
- Time-poor → density
- Power → load step (after bar speed is maxed)

**Key rule:** Make the mechanism's metric the HEADLINE number. A density user sees "reps in 20 minutes," not bar weight.

**Equipment limits:** When a user has only one pair of dumbbells, switch to total-rep or density (load stepping is impossible).

**Time-box every block:** 6 weeks is the sweet spot — long enough to force adaptation, short enough that the body doesn't habituate.

### 5. Deload and Backing Off (§5)
The book's recovery logic:
- Stop sets 1-2 reps short of failure (unless protocol says otherwise)
- When reps can't be completed, rest briefly and finish (don't grind)
- Machines are the sensible choice for someone banged up

**Back-off week triggers (any of these):**
- Two consecutive missed top sets on one lift
- Joint-pain flag on 2 sessions in 7 days
- Low sleep/soreness scores 3 sessions running
- End of a 6-week block

**What a back-off week looks like:**
- Keep exercises and pattern coverage
- Drop load 10-20%
- Remove the LAST SET of everything
- The session is NOT cancelled — the user still shows up

**Baseline instruction everywhere:** Leave 1-2 reps in the tank. Failure is a labelled technique for INTERMEDIATES on isolation work ONLY.

### 6. Exercise Selection and Substitution (§6)
**The premise:** The CONSTRAINT (equipment, space, time, joints) picks the exercise while the PATTERN stays fixed.

**Equipment ladder (barbell → bodyweight):**
barbell → dumbbells → single dumbbell → band → suspension trainer → bodyweight → playground bar

Every pattern MUST have a bodyweight fallback, even pulling (inverted row, door row).

**By joint tolerance:**
- Shoulder hurts → palms-facing grip for pressing, slight incline instead of flat
- Wrists/elbows ache → curved bar instead of straight
- Everything hurts → machines (they stabilize the load for you)

**By available load (when weight is too light):**
Reach for these IN ORDER:
1. Slow the tempo
2. Work one limb at a time
3. Shorten rest
4. Run a circuit
5. Raise reps
6. Change leverage (elevate feet, lengthen body angle)

Mismatched dumbbells are a FEATURE — asymmetry makes the trunk work.

**CRITICAL RULE:** Substitution is a lookup on (pattern, equipment, joint flags) IN THAT PRIORITY. **NEVER substitute across patterns.** Report "no pull available" rather than quietly swapping in a push.

**By sequencing:**
- Heavy compound first, isolation last
- Light activation move before a hard single-leg lift
- Circuit pairings must be NON-COMPETING (upper with lower, push with pull) so fatigue doesn't carry over
- In a fixed-load complex, the weakest movement sets the load
- When ability is unknown, prescribe reps for TIME so strong and weak users both get a useful set

### 7. Warm-Up Structure (§7)
The book tiers warm-ups by TIME AVAILABLE and injury history:

**Full tier** (hour+, or injury history):
- Soft-tissue work on habitual tight spots
- Few minutes easy pulse-raising
- Dynamic sequence taking joints through the session's ranges
- Static holds ONLY for chronically tight areas

**Practical tier** (short on time):
- Few minutes on cardio machine
- 1-2 mobility drills for hips and upper back

**Work-up sets (MANDATORY before any heavy lift):**
- Start with empty bar or trivial resistance
- Add weight in steps while cutting reps to save energy
- Arrive at working load ready
- Rests stay short until loads get heavy
- For 4-8-rep working set → final single SLIGHTLY ABOVE working weight so real set feels lighter
- For true max attempt → back off one set before climbing again (loads feel heaviest near 90%, lighter set restores confidence)

**Product rules:**
- Ask "minutes available today" at session start
  - Under 45 → practical
  - 45-60 → practical + dynamic
  - Over 60 or injury flag → full
- Generate work-up sets from day's target load:
  - 4-5 steps for heavy top set
  - 2 for moderate
  - NONE for circuits
- Apply overshoot single only for 4-8-rep targets and intermediate users
- A lower-body warm-up screen still includes ONE upper-body drill, and vice versa

### 8. Strength, Hypertrophy, Conditioning — What Changes (§8)
The sessions differ by goal along FOUR axes: reps, rest, pairing, and what you try to beat next time.

**Strength:**
- Low reps, heavy loads
- Sets whose reps sum to ~24 on the main lift
- Long rests, straight sets
- First few sets are warm-ups, only last couple are truly heavy
- Progression = bar weight
- Forced reps/dropsets are demoted below "add weight"

**Hypertrophy:**
- Moderate reps (8-15)
- Three working sets as the sweet spot
- Deliberate tempo (slow lowering, squeeze at top)
- Several angles per muscle
- Sets stopped shy of failure
- Blood-flow tricks (stretching between sets, peak contractions)

**Recomposition / Fat Loss:**
- Same moderate reps
- Paired upper-with-lower or push-with-pull
- Rests UNDER A MINUTE
- Reasoning: rising lactate drives hormonal response
- Progression = rest compression
- **The book is blunt:** Long slow cardio is NOT the efficient fat-loss tool — circuits and intervals are

**Conditioning:**
- Intervals set as % of estimated max HR
- Work-to-rest ratios (2:1 for very short all-out, 1:2 for longer)
- Ladders that climb and descend
- Density blocks scored on work done in a window

**Power:**
- Very few reps, maximum speed
- Implements that can be released (throws) so body needn't decelerate
- Light, fast barbell reps also clear sticking points

**Product rules:**
- Goal tag sets FOUR defaults: rep range, rest range, pairing mode, progression mechanism
- Users may override one, but app warns when override contradicts goal (strength user cutting rest to 30s)
- Heart-rate conditioning needs max-HR estimate (220 - age as fallback) and a no-monitor method: 6-second pulse count × 10
- On "I want to lose fat, give me a running plan" → offer circuit or interval plan FIRST with trade-off explained (still allow running for users who enjoy it)
- Power blocks are intermediate-only add-on with eased-in hill-style progression

### 9. Form-Cue Categories (§9)
The book uses a small repeating vocabulary. Grouped into 8 buckets for coaching copy and pain triage:

1. **Spine position** — keep natural lower-back arch; never round; don't go so deep tailbone tucks
2. **Bracing** — abs braced, glutes squeezed, grip tight (how trunk trains on compounds)
3. **Joint alignment** — knees over feet, elbows in line with wrists, elbows tucked ~45° on presses
4. **Anti-movement** — hips level, shoulders square, no sway/twist/hip drop
5. **Range-of-motion limits** — "as low as you can WITHOUT losing X"; depth always conditional on spine/alignment cue
6. **Tempo and pauses** — 1-sec squeeze at top, 3-5 sec lowering, pause at sticking point (bottom of squat is book's favorite)
7. **Force direction** — drive feet into floor, explode through hips
8. **Stop rules** — end set when form breaks; stop 1-2 reps before failure; rest briefly and finish rather than grind

**Product rules:**
- Each exercise carries AT MOST 3 cues, one of which MUST be a stop rule or ROM limit
- On pain report → ask WHERE and map location to categories 1, 3, 5 for that exercise before proposing substitution
- Form-feedback features classify user-reported issues into these 8 buckets so coaching stays consistent

### 10. Beginner vs Intermediate (§10)
**Beginner prescription (unglamorous):**
- Three patterns, three sessions a week, straight sets
- Rotating rep ranges
- Machines allowed if they reduce risk
- Pyramid sets (lighter/higher-rep first, heavier later) teach movement while warming up

**Intermediates get the rest:**
- Upper/lower splits
- Body-part emphasis days (still obeying balance rule)
- Max-effort work
- Supersets and trisets
- Dropsets ordered by mechanical advantage (hardest grip first)
- Six-week specialty blocks
- "Shock" protocols for stale body part (used sparingly)

**Product rules:**
- Classify as beginner until ~12 consecutive logged weeks AND a load benchmark on main lower-body lift (book's "legs aren't growing" heuristic = squat at 1.5× bodyweight; use a softer bar but use one)
- Beginner mode HIDES: supersets, dropsets, tempo beyond "control the lowering," max-effort days, specialty blocks
- Beginner mode SHOWS: full-body rotation, work-up sets, 3 cues per lift, 1 progression mechanism
- Intermediate mode unlocks techniques ONE AT A TIME, each with block length and exit condition
- At any level, "same thing for months, stalled" → scheme rotation or 6-week block FIRST, not a new exercise list
